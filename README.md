# Betawave

Beta Wave is a Windows desktop music player developed in 2024 as my final college software development project.

The application supports user accounts, music libraries, playlists and audio playback.

## Technologies

- **C# / .NET 8 MAUI** — Application framework
- **XAML / MVVM** — User interface and architecture
- **NAudio** — Audio playback
- **MySQL / MariaDB** — Database management

## Project Notes

The application requires a separate local database server, originally managed through XAMPP, for login and other database-dependent functionality.

The original music files and album artwork have been removed from the public repository for copyright reasons. Some references to their original file paths remain.

I am currently working towards reviving the project and replacing the external database with an embedded database to simplify setup and make the application easier to run independently.
